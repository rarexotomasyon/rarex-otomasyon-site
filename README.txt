RAREX OTOMASYON WEB SİTESİ

Dosyalar:
- index.html: Ana sayfa
- style.css: Tasarım
- gizlilik-politikasi.html: Gizlilik politikası
- hizmet-sartlari.html: Hizmet şartları

Yükleme:
1. ZIP'i bilgisayarınıza çıkarın.
2. GitHub'da rarex-otomasyon-site deposunu açın.
3. Add file > Upload files seçin.
4. Çıkardığınız klasörün içindeki dört dosyayı yükleme alanına sürükleyin.
5. Commit changes ile kaydedin.
6. Birkaç dakika sonra GitHub Pages adresini açın.

ÖNEMLİ:
Gizlilik politikası ve hizmet şartları sayfalarında iletişim adresi parartstring@gmail.com olarak ayarlanmıştır. Metinler başlangıç taslağıdır; uygulamanın gerçek veri akışına göre kontrol edilmelidir. TikTok doğrulama TXT dosyanızı silmeyin. TikTok yeni dosya üretirse onu da deponun kök dizinine ekleyin.
